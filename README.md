# MAANG-Interview-Prep-100-DSA

A curated, battle-tested collection of ~100 high-impact Data Structures and Algorithms
problems frequently asked in interviews at **MAANG (Meta, Apple, Amazon, Netflix, Google)
and other top-tier product companies** — organized by topic and pattern so you can build
the underlying problem-solving muscle that interview rounds actually test.

The full problem track lives in [`MAANG-Interview-Prep-100-DSA-main/README.md`](MAANG-Interview-Prep-100-DSA-main/README.md).

## Contents

- **18 topic tracks** — Array, String, Linked List, Two Pointers, Sliding Window, Stack,
  Trees (BFS/DFS + advanced/BST), Heap/Priority Queue, Backtracking, DP (1D and 2D/advanced),
  Graphs (BFS/DFS/Union-Find + shortest paths), Binary Search, Greedy, Math & Bit
  Manipulation, Intervals.
- Each problem links straight to its LeetCode page, tagged with difficulty
  (Easy/Medium/Hard), core concepts, why MAANG interviews love it, and its source
  (LeetCode Top, Blind 75, NeetCode 150). ⭐ marks especially high-frequency,
  foundational problems.
- Curated by cross-referencing LeetCode's "Top Interview Questions", Blind 75,
  NeetCode 150, and aggregated interview experiences from LeetCode Discuss/Glassdoor —
  prioritizing recurring patterns over exact questions.

## How to Use

1. Start with the topic you're weakest in — Array and String are good first tracks.
2. Work problems in the listed order; they ramp in difficulty within each track.
3. For every problem: solve it, then re-derive the pattern (two pointers, prefix sums,
   DP state design) in your own words before moving on.
4. No build, no dependencies — it's pure Markdown. Fork it and check off problems
   as you go.

## Suggested Study Plan

- **Weeks 1–2:** Array, String, Two Pointers, Sliding Window, Stack (~25 problems)
- **Weeks 3–4:** Linked List, Trees, Heap, Binary Search (~25 problems)
- **Weeks 5–6:** DP 1D, DP 2D/advanced, Backtracking, Greedy (~25 problems)
- **Weeks 7–8:** Graphs (both tracks), Intervals, Math & Bit (~25 problems)
- Then: re-attempt every ⭐ problem under timed conditions.
